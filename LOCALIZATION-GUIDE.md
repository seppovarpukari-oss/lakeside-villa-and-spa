# TLVS Localization Editorial Rule

## Governing source
- en-GB production copy is the approved editorial master.
- It is NOT a sentence-structure template.
- It IS the complete content, meaning, explanatory depth, concrete observation and tone master.

## Non-negotiable rule
Each target language must read as if the text had originally been written by a strong native editorial writer in that language.

Naturalness is achieved by changing syntax, sentence boundaries, idiom, rhythm and word order — NOT by deleting, compressing, abstracting or sloganising meaning.

## Do not
- translate sentence by sentence
- follow English syntax mechanically
- compress merely because the text is for the web
- turn concrete description into abstract marketing language
- replace explanations with slogans
- reduce paragraph length to 1, 2 or 3 sentences by rule
- use another localization as the source for a different language

## Do
- preserve every substantive idea, explanation, relationship, concrete observation and factual nuance from en-GB
- write directly from en-GB into each target language independently
- use as many sentences as natural clarity requires
- prefer clear, concrete, easily understood language over cleverness
- let paragraphs breathe
- keep Quiet Luxury tone: calm, specific, place-aware, understated
- preserve locked facts and locked names exactly

## Mandatory QA for every paragraph
1. Native read: Does this sound as if a native writer wrote it without seeing English?
2. Meaning check: Is every substantive English idea still present?
3. Clarity check: Is it easy to understand on first read?
4. Anti-compression check: Was anything shortened merely to make the copy tighter?
5. Fact check: Are all locked facts unchanged?

If any answer fails, the paragraph is rejected.

## Important historical lesson
A previous localization pass failed because en-GB was treated as "facts + meaning" and the localized copy was re-written as shorter web copy. That is explicitly wrong. The approved English copy represents the full editorial content. Localizations may sound completely different structurally, but they must not be semantically thinner or less descriptive.
